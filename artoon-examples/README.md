# ARTOON Examples

هذا المجلد يحتوي على أمثلة شاملة لصيغة ARTOON.

## الملفات

### complete-syntax-showcase.artoon

مقال شامل يعرض **جميع** إمكانيات صيغة ARTOON Core v1:

1. **المكونات النصية** — p, t1-t6, q, pre
2. **المُعدِّلات السبعة** — s, e, u, d, mark, sub, sup
3. **المُعدِّلات المدمجة** — s+e, s+u, s+e+u, etc.
4. **المكونات الداخلية** — a, c, img, time, abbr, video, audio, file
5. **الفواصل** — hr, br, wbr
6. **التعليقات** — >::: و <.:::
7. **القوائم** — ul, ol, dl
8. **الجداول** — table
9. **الوسائط** — img, video, audio, file, a
10. **البلوكات** — code, meta, custom blocks
11. **المكونات المركبة** — figure, details
12. **الحقول المخفية** — >.-:field:
13. **المكونات الفرعية** — >.-type::
14. **دعم الاتجاهين** — RTL و LTR

## كيفية الاختبار

1. افتح المحرر ARTOON INTYPE
2. اختر "فتح من الجهاز" من قائمة الملفات
3. اختر الملف `complete-syntax-showcase.artoon`
4. اضغط على زر "🧪 Test Syntax" للتحقق من دعم الصيغة

## الصيغة المرجعية

راجع `Core Invariants/SYNTAX-REFERENCE.md` للمرجع الرسمي للصيغة.
