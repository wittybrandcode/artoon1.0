# ARTOON Inline Component Attributes

**توصيفات المكونات الداخلية**

---

## 1. المبدأ الأساسي

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   الوجود هو الأصل                                                      │
│   الغياب لا يؤثر                                                       │
│                                                                         │
│   كل توصيف له جدوى دلالية سرمدية                                       │
│   لا توصيفات تصميمية                                                   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

**القاعدة:**
- التوصيف الأول (المسار/القيمة) دائماً إلزامي
- التوصيفات الإضافية اختيارية
- غياب التوصيف الاختياري لا يُبطل المكون
- الترتيب ثابت: الأساس أولاً، ثم التفاصيل

---

## 2. قائمة المكونات الداخلية

### 2.1 الرابط (`a`)

```artoon
[a:: url]
[a:: url; نص]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `url` | 1 | ✓ | عنوان الوجهة |
| `نص` | 2 | ○ | نص العرض (إن غاب = url) |

**أمثلة:**
```artoon
[a:: https://example.com]
[a:: https://example.com; اضغط هنا]
[a:: /docs/guide; دليل الاستخدام]
[a:: #section; القسم التالي]
```

**الجدوى:**
- `url`: تحديد الوجهة (داخلية/خارجية تُحسب تلقائياً)
- `نص`: نص بديل للعرض بدل الرابط الخام

---

### 2.2 الصورة (`img`)

```artoon
[img:: path]
[img:: path; alt]
[img:: path; alt; title]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `path` | 1 | ✓ | مسار الصورة |
| `alt` | 2 | ○ | نص بديل (للقارئ الآلي) |
| `title` | 3 | ○ | عنوان (تلميح عند التمرير) |

**أمثلة:**
```artoon
[img:: logo.svg]
[img:: photo.jpg; صورة المؤلف]
[img:: diagram.png; مخطط البنية; انقر للتكبير]
```

**الجدوى:**
- `path`: تحديد مصدر الصورة
- `alt`: وصف للقارئ الآلي (accessibility)
- `title`: معلومة إضافية للمستخدم

**ملاحظة:** غياب `alt` و `title` لا يُبطل الصورة.

---

### 2.3 الصوت (`audio`)

```artoon
[audio:: path]
[audio:: path; title]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `path` | 1 | ✓ | مسار الملف الصوتي |
| `title` | 2 | ○ | عنوان/وصف المقطع |

**أمثلة:**
```artoon
[audio:: podcast.mp3]
[audio:: interview.mp3; مقابلة مع المؤسس]
[audio:: sound-effect.wav; صوت التنبيه]
```

**الجدوى:**
- `path`: تحديد مصدر الصوت
- `title`: وصف دلالي للمقطع الصوتي

---

### 2.4 الفيديو (`video`)

```artoon
[video:: path]
[video:: path; title]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `path` | 1 | ✓ | مسار ملف الفيديو |
| `title` | 2 | ○ | عنوان/وصف المقطع |

**أمثلة:**
```artoon
[video:: demo.mp4]
[video:: tutorial.mp4; شرح التثبيت]
[video:: presentation.webm; العرض التقديمي الكامل]
```

**الجدوى:**
- `path`: تحديد مصدر الفيديو
- `title`: وصف دلالي للمقطع المرئي

---

### 2.5 الملف (`file`)

```artoon
[file:: path]
[file:: path; label]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `path` | 1 | ✓ | مسار الملف |
| `label` | 2 | ○ | اسم العرض (إن غاب = اسم الملف) |

**أمثلة:**
```artoon
[file:: report.pdf]
[file:: data.xlsx; تقرير المبيعات 2026]
[file:: archive.zip; النسخة الكاملة]
```

**الجدوى:**
- `path`: تحديد مصدر الملف
- `label`: اسم وصفي بدل اسم الملف التقني

---

### 2.6 الاختصار (`abbr`)

```artoon
[abbr:: short; full]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `short` | 1 | ✓ | النص المختصر |
| `full` | 2 | ✓ | التوسعة الكاملة |

**أمثلة:**
```artoon
[abbr:: HTML; HyperText Markup Language]
[abbr:: API; Application Programming Interface]
[abbr:: ذ.م.م; ذات مسؤولية محدودة]
```

**الجدوى:**
- `short`: الاختصار المعروض
- `full`: المعنى الكامل (للفهم والـ accessibility)

**ملاحظة:** كلا التوصيفين إلزامي — الاختصار بلا توسعة لا معنى له.

---

### 2.7 التاريخ/الوقت (`time`)

```artoon
[time:: ISO]
[time:: ISO; نص]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `ISO` | 1 | ✓ | التاريخ بصيغة ISO 8601 |
| `نص` | 2 | ○ | نص العرض (إن غاب = ISO) |

**صيغ ISO المدعومة:**
```
2026-01-06          ← تاريخ
2026-01-06T14:30    ← تاريخ ووقت
14:30               ← وقت فقط
2026-W02            ← أسبوع
2026-01             ← شهر
```

**أمثلة:**
```artoon
[time:: 2026-01-06]
[time:: 2026-01-06; السادس من يناير]
[time:: 2026-01-06T14:30; الثانية والنصف ظهراً]
[time:: 14:30; وقت الاجتماع]
```

**الجدوى:**
- `ISO`: قيمة آلية قابلة للمعالجة
- `نص`: عرض بشري مقروء

---

### 2.8 الكود السطري (`c`)

```artoon
[c:: code]
[c:: code; lang]
```

| التوصيف | الموضع | إلزامي | الوصف |
|---------|--------|--------|-------|
| `code` | 1 | ✓ | الكود |
| `lang` | 2 | ○ | لغة البرمجة |

**أمثلة:**
```artoon
[c:: console.log()]
[c:: console.log(); js]
[c:: print("مرحبا"); python]
[c:: SELECT * FROM users; sql]
[c:: npm install; bash]
```

**الجدوى:**
- `code`: الكود المعروض كما هو
- `lang`: تحديد اللغة (للتلوين، tooltip، أو الأرشفة)

**ملاحظة:** غياب `lang` لا يُبطل الكود — يُعرض كنص عادي.

## 3. جدول مرجعي

| المكون | الصيغة | التوصيفات |
|--------|--------|-----------|
| `a` | `[a:: url; نص]` | url ✓, نص ○ |
| `img` | `[img:: path; alt; title]` | path ✓, alt ○, title ○ |
| `audio` | `[audio:: path; title]` | path ✓, title ○ |
| `video` | `[video:: path; title]` | path ✓, title ○ |
| `file` | `[file:: path; label]` | path ✓, label ○ |
| `abbr` | `[abbr:: short; full]` | short ✓, full ✓ |
| `time` | `[time:: ISO; نص]` | ISO ✓, نص ○ |
| `c` | `[c:: code; lang]` | code ✓, lang ○ |

**الرموز:**
- ✓ = إلزامي
- ○ = اختياري

---

## 4. قواعد عامة

### 4.1 الترتيب ثابت

```
✓ صحيح:  [img:: photo.jpg; وصف الصورة]
✗ خطأ:   [img:: وصف الصورة; photo.jpg]
```

### 4.2 الفاصل

```
; = فاصل بين التوصيفات
```

### 4.3 الغياب مقبول

```artoon
[img:: photo.jpg]           ← بدون alt أو title ✓
[time:: 2026-01-06]         ← بدون نص عرض ✓
[c:: code]                  ← بدون lang ✓
```

### 4.4 لا توصيفات إضافية

```
هذه القائمة مغلقة ونهائية.
لا يُسمح بإضافة توصيفات خارج هذا التعريف.
```

## 5. أمثلة شاملة

```artoon
>.p:: في [time:: 2026-01-06; يناير 2026] نشرنا [a:: https://docs.artoon.dev; الوثائق] التي تشرح [abbr:: ARTOON; Advanced Rich Text Object Oriented Notation].

>.p:: استخدم [c:: npm install artoon; bash] للتثبيت، ثم [c:: import { parse } from 'artoon'; js] في الكود.

>.p:: الشعار [img:: logo.svg; شعار ARTOON] والعرض التقديمي [video:: intro.mp4; مقدمة سريعة].

>.p:: حمّل [file:: guide.pdf; دليل المستخدم] أو استمع إلى [audio:: podcast.mp3; الحلقة الأولى].
```
