# ARTOON Lists System

**نظام القوائم**

## 1. أنواع القوائم

### 1.1 قائمة غير مرتبة (ul)

```artoon
>.ul::
li:: عنصر أول
li:: عنصر ثاني
li:: عنصر ثالث
```

**HTML:**
```html
<ul>
  <li>عنصر أول</li>
  <li>عنصر ثاني</li>
  <li>عنصر ثالث</li>
</ul>
```

---

## 2. نظام التداخل بالشرطات

### 2.1 القاعدة الأساسية

```
عدد الشرطات = مستوى التداخل

li::      ← مستوى 0
-li::     ← مستوى 1
--li::    ← مستوى 2
---li::   ← مستوى 3
```

### 2.2 وراثة الاتجاه

```
✓ عناصر القوائم (li, dt, dd, tr, th) ترث الاتجاه من الحاوية الأب
✓ لا حاجة لتكرار > أو < في كل عنصر
```

### 2.3 مثال بسيط

```artoon
>.ul::
li:: Coffee
-li:: Coffee milk 1
-li:: Coffee milk 2
li:: Tea
li:: Milk
```

**HTML:**
```html
<ul>
  <li>Coffee
    <ul>
      <li>Coffee milk 1</li>
      <li>Coffee milk 2</li>
    </ul>
  </li>
  <li>Tea</li>
  <li>Milk</li>
</ul>
```

## 3. القوائم المختلطة

### 3.1 القاعدة

```
✓ كل قائمة فرعية تحتاج تصريح نوعها صراحة
✓ لا توجد قوائم ضمنية
✓ التصريح الصريح يمنع الغموض
```

### 3.2 مثال مختلط

```artoon
>.ul::
li:: الفواكه
-ol::
-li:: التفاح
--ul::
--li:: أحمر
--li:: أخضر
-li:: البرتقال
-li:: الموز
li:: الخضروات
-ul::
-li:: الطماطم
-li:: الخيار
li:: المصطلحات
-dl::
-dt:: HTML
-dd:: لغة ترميز
-dt:: CSS
-dd:: لغة تنسيق
li:: نهاية القائمة
```

**HTML:**
```html
<ul>
  <li>الفواكه
    <ol>
      <li>التفاح
        <ul>
          <li>أحمر</li>
          <li>أخضر</li>
        </ul>
      </li>
      <li>البرتقال</li>
      <li>الموز</li>
    </ol>
  </li>
  <li>الخضروات
    <ul>
      <li>الطماطم</li>
      <li>الخيار</li>
    </ul>
  </li>
  <li>المصطلحات
    <dl>
      <dt>HTML</dt>
      <dd>لغة ترميز</dd>
      <dt>CSS</dt>
      <dd>لغة تنسيق</dd>
    </dl>
  </li>
  <li>نهاية القائمة</li>
</ul>
```

## 4. قواعد الإغلاق

### 4.1 الإغلاق الضمني

```
✓ القائمة تُغلق عند العودة لمستوى أقل
✓ القائمة تُغلق عند ظهور مكون جديد >.type::
✓ القائمة تُغلق عند نهاية الملف
```

### 4.2 مثال الإغلاق

```artoon
>.ul::
li:: عنصر 1
-li:: فرعي 1.1
-li:: فرعي 1.2
li:: عنصر 2          ← أغلق الفرعيات، عد لمستوى 0
>.p:: فقرة جديدة     ← أغلق القائمة كلها
```

---

## 5. خوارزمية التحليل

```
1. احسب عدد الشرطات (depth)
2. إذا depth > currentDepth:
   - افتح قائمة جديدة من النوع المصرح
   - أضف العنصر
3. إذا depth == currentDepth:
   - أغلق العنصر السابق
   - أضف عنصر جديد
4. إذا depth < currentDepth:
   - أغلق (currentDepth - depth) مستويات
   - أضف عنصر جديد
5. currentDepth = depth
```
