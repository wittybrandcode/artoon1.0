## المبادئ الستة الثابتة

### 1. السطر = وحدة معنى

كل سطر يمثل وحدة دلالية واحدة غير قابلة للتجزئة.

```
✓ سطر واحد = فكرة واحدة
✓ لا توجد وحدات معنى تمتد على أسطر متعددة (باستثناء الكود)
```

### 2. المعنى قبل الشكل

أي معلومة بصرية أو سلوكية أو تنفيذية ممنوعة داخل ARTOON.

```
✗ الألوان
✗ الأبعاد
✗ الخطوط
✗ التخطيط
✗ التفاعل
✗ السلوك
```

### 3. السياق بدل الإغلاق

السياق يُفتح ضمنياً ويُغلق ضمنياً عند فتح سياق جديد.

```
✓ لا توجد علامات إغلاق صريحة للمكونات
✓ البلوكات والكود لها إغلاق صريح (استثناء)
✓ المستوى يُحدد بالشرطات
✓ فتح type جديد يُغلق ما قبله
```

### 4. الرابط المفسَّر عنصر أساسي

كل محتوى غير نصي يُمثَّل كرابط ذي نوع دلالي.

```
✓ الصورة = رابط من نوع img
✓ الفيديو = رابط من نوع video
✓ الصوت = رابط من نوع audio
```

### 5. الاتجاه جزء من البنية (Direction-Aware)

اتجاه النص (RTL / LTR) مدمج في الصيغة وليس بيانات وصفية.
كلا الاتجاهين متساويان — لا أفضلية لأي لغة.

```
✓ > = RTL (Arabic, Hebrew, Persian, Urdu, ...)
✓ < = LTR (English, French, German, Chinese, ...)
✓ كل سطر يبدأ بأحدهما
✓ يمكن خلط الاتجاهات في نفس المستند
✓ لا أفضلية لاتجاه على آخر
```

### 6. نقاء التخزين

أي معلومة يمكن استنتاجها لاحقاً لا تُخزَّن الآن.

```
✓ لا تكرار
✓ لا معلومات مشتقة
✓ الحقيقة الأساسية فقط
```

## ما هو خارج النطاق صراحة

يُمنع وجود ما يلي داخل ARTOON Core:

| الفئة | أمثلة |
|-------|-------|
| التخطيط | grid, flex, columns |
| الأبعاد | width, height, margin |
| الألوان | color, background |
| الخطوط | font-family, font-size |
| التفاعل | onclick, hover |
| السلوك | autoplay, loop |
| التوافق | fallback, polyfill |
