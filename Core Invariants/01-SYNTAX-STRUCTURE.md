# ARTOON Syntax Structure

**البنية القياسية للصيغة**

---

## 1. البنية الأساسية للسطر

```
>.type:: content
<.type:: content
```

### 1.1 الرموز البنيوية

| الرمز | المعنى | إلزامي |
|-------|--------|--------|
| `>` | محتوى باتجاه RTL | ✓ |
| `<` | محتوى باتجاه LTR | ✓ |
| `.` | تصريح مكوّن | ✓ |
| `type` | نوع دلالي | ✓ |
| `::` | فاصل المحتوى الآمن | ✓ |
| ` ` | مسافة بعد `::` | ✓ |
| `;` | فاصل قيم متعددة | اختياري |
| `-` | مستوى التداخل | اختياري |

### 1.2 قاعدة المسافة

```
✓ صحيح:  >.p:: نص الفقرة
✗ خطأ:   >.p::نص الفقرة
```

**المسافة بعد `::` إلزامية دائماً**

---

## 2. نموذج الاتجاه

### 2.1 القواعد

```
✓ كل سطر يجب أن يبدأ بـ > أو <
✓ الاتجاه يؤثر على القراءة فقط
✓ الاتجاه لا يغيّر المعنى الدلالي
```

### 2.2 أمثلة

```artoon
>.p:: هذا نص عربي من اليمين لليسار
<.p:: This is English text from left to right
```

---

## 3. الفاصل الآمن `::`

### 3.1 لماذا `::`؟

```
✓ يضمن أن المحتوى لن يتعارض مع الرموز البنيوية
✓ يسمح باستخدام : و ; و [ داخل المحتوى بحرية
✓ Parser أبسط وأكثر موثوقية
```

### 3.2 أمثلة

```artoon
>.p:: النسبة 1:2:3 بدون مشاكل
>.p:: قيم متعددة; في نص واحد
>.p:: أقواس [مربعة] بدون تفسير
```

---

## 4. القيم المتعددة

### 4.1 الصيغة

```
>.type:: قيمة1; قيمة2; قيمة3
```

### 4.2 الترتيب ثابت لكل نوع

| النوع | الترتيب |
|-------|---------|
| `a` | رابط; نص |
| `img` | مسار |
| `video` | مسار |
| `audio` | مسار |

### 4.3 أمثلة

```artoon
>.a:: https://example.com; اضغط هنا
>.img:: photo.jpg
```

---

## 5. مستويات التداخل

### 5.1 الصيغة

```
-type::     ← مستوى 1
--type::    ← مستوى 2
---type::   ← مستوى 3
```

### 5.2 القاعدة

```
عدد الشرطات = مستوى التداخل
```

### 5.3 مثال

```artoon
>.ul::
li:: عنصر مستوى 0
-li:: عنصر مستوى 1
--li:: عنصر مستوى 2
-li:: عودة لمستوى 1
li:: عودة لمستوى 0
```

---

## 6. التعليقات

### 6.1 الصيغة

```artoon
>.::: تعليق عربي
<.::: English comment
```

### 6.2 التعليقات متعددة الأسطر

```artoon
>.::: هذا تعليق
يمتد على عدة أسطر
حتى يظهر مكون جديد
>.p:: هنا انتهى التعليق
```

### 6.3 القاعدة

```
✓ أي سطر بـ >.::: أو <.::: يُعد تعليقاً
✓ يخضع لقواعد الاتجاه
✓ يُتجاهل عند التحليل
✓ يستمر حتى ظهور مكون جديد مُعرَّف
```

## 7. السلوكيات الأساسية

### 7.1 الأسطر الفارغة

```
✓ الأسطر الفارغة للتنظيم البصري فقط
✓ لا قيمة دلالية لها
✓ يُستحسن تفاديها لربح الموارد
```

### 7.2 امتداد السطر

```
✓ السطر يمتد بلا حدود
✓ النزول للسطر التالي للتنظيم فقط
✓ فتح type جديد هو الذي يُغلق ما قبله
```

### 7.3 قاعدة الإغلاق

```
✓ فتح مكون جديد >.type:: يُغلق المكون السابق
✓ لا يوجد إغلاق صريح للمكونات
✓ البلوكات والكود استثناء (لها إغلاق صريح)
```
