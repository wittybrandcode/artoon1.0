# ARTOON Blocks System

**نظام البلوكات**

---

## 1. المفهوم

البلوكات = حاويات لتجميع المكونات تحت اسم واحد.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   ✓ البلوك = مجموعة مكونات                                             │
│   ✓ لا يشترط اتجاه للبلوك نفسه                                         │
│   ✓ المحتوى الداخلي يتبع قواعد ARTOON                                  │
│   ✓ البلوكات قابلة للتوسع بلا حدود                                     │
│   ✓ بلوك واحد فقط محجوز: code                                          │
│   ✓ جميع البلوكات الأخرى (بما فيها meta) = بلوكات مخصصة               │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 2. الصيغة الأساسية

### 2.1 فتح وغلق البلوك

```
<blockname>.     ← بداية البلوك (النقطة بعد الاسم)
محتوى
.<blockname>     ← نهاية البلوك (النقطة قبل الاسم)
```

### 2.2 مثال بسيط

```artoon
<post>.
>.t2:: عنوان المقال
>.p:: محتوى المقال
>.img:: cover.jpg
.<post>
```

### 2.3 HTML الناتج

```html
<div class="post">
  <h2>عنوان المقال</h2>
  <p>محتوى المقال</p>
  <img src="cover.jpg">
</div>
```

## 3. البيانات الوصفية (meta) — بلوك مخصص

**ملاحظة مهمة:** `meta` ليس بلوكاً محجوزاً — هو بلوك مخصص يُستخدم **اصطلاحاً** للبيانات الوصفية.

### 3.1 الصيغة

```artoon
<meta>.
>.-:title: عنوان المستند
>.-:lang: ar
>.-:author: اسم الكاتب
>.-:date: 2026-01-05
>.-:version: 1.0
.<meta>
```

### 3.2 صيغة الحقول المحجوزة

```
>.-:fieldname: value
```

| الجزء | المعنى |
|-------|--------|
| `>` | اتجاه المحتوى |
| `.-:` | تصريح حقل محجوز |
| `fieldname` | اسم الحقل |
| `:` | فاصل |
| `value` | القيمة |

### 3.3 الحقول المحجوزة المعيارية

| الحقل | الوصف |
|-------|-------|
| `title` | عنوان المستند |
| `lang` | اللغة الرئيسية |
| `dir` | الاتجاه الافتراضي |
| `author` | الكاتب |
| `date` | تاريخ الإنشاء |
| `modified` | تاريخ التعديل |
| `version` | إصدار المستند |
| `description` | وصف مختصر |
| `tags` | وسوم (مفصولة بـ ;) |

## 4. بلوك الكود (code) — البلوك المحجوز الوحيد

### 4.1 كود بسيط

```artoon
<code>.
const x = 1;
console.log(x);
.<code>
```

### 4.2 كود مع تحديد اللغة

```artoon
<code:js>.
const x = 1;
console.log(x);
.<code>

<code:python>.
x = 1
print(x)
.<code>

<code:html>.
<div class="container">
  <p>Hello</p>
</div>
.<code>
```

### 4.3 HTML الناتج

```html
<pre><code class="language-js">
const x = 1;
console.log(x);
</code></pre>
```

**ملاحظة:** بلوك الكود محجوز ويُعامل بشكل خاص - المحتوى الداخلي لا يُحلَّل كـ ARTOON.

## 5. أمثلة متنوعة

### 5.1 بطاقة (card)

```artoon
<card>.
>.img:: product.jpg
>.t3:: اسم المنتج
>.p:: وصف المنتج
>.a:: https://buy.com; اشترِ الآن
.<card>
```

### 5.2 تنبيه (alert)

```artoon
<alert>.
>.t4:: تحذير
>.p:: هذا الإجراء لا يمكن التراجع عنه
.<alert>
```

### 5.3 قسم (section)

```artoon
<section>.
>.t2:: القسم الأول
>.p:: مقدمة القسم
>.ul::
li:: نقطة أولى
li:: نقطة ثانية
.<section>
```

### 5.4 مستند كامل

```artoon
<meta>.
>.-:title: دليل ARTOON
>.-:lang: ar
>.-:version: 1.0
.<meta>

<header>.
>.t1:: دليل ARTOON الشامل
>.p:: مرجعك الكامل لصيغة ARTOON
.<header>

<main>.
>.t2:: المقدمة
>.p:: ARTOON صيغة محتوى دلالي...

>.t2:: المكونات
>.p:: تتكون ARTOON من...
.<main>

<footer>.
>.p:: جميع الحقوق محفوظة 2026
.<footer>
```

## 7. قواعد البلوكات

### 7.1 التسمية

```
✓ أحرف إنجليزية صغيرة
✓ أرقام (ليس في البداية)
✓ شرطة - (ليس في البداية أو النهاية)
✗ مسافات
✗ رموز خاصة
```

أمثلة صالحة: `post`, `my-card`, `section2`
أمثلة خاطئة: `My Post`, `2section`, `-card-`

### 7.2 الإغلاق

```
✓ كل بلوك يجب أن يُغلق بنفس اسمه
✓ البلوكات المتداخلة تُغلق من الداخل للخارج
✗ لا يمكن ترك بلوك مفتوح
```

### 7.3 المحتوى

```
✓ أي مكون ARTOON صالح
✓ بلوكات أخرى (تداخل)
✓ أسطر فارغة (للتنظيم فقط)
```

## 8. ملخص البلوكات

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         نظام البلوكات في ARTOON                         │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  الفتح:       <blockname>.                                             │
│  الغلق:       .<blockname>                                             │
│                                                                         │
│  البلوك المحجوز الوحيد:                                                 │
│  - code:      للكود متعدد الأسطر (<code:lang>.)                        │
│               المحتوى لا يُحلَّل كـ ARTOON                              │
│                                                                         │
│  البلوكات المخصصة (جميع البلوكات الأخرى):                              │
│  - meta:      يُستخدم اصطلاحاً للبيانات الوصفية                        │
│  - أي اسم:    post, card, section, header, footer, ...                 │
│                                                                         │
│  HTML:        يمكن تحويل أي بلوك لأي tag                               │
│               <div class="blockname">...</div> (افتراضي)               │
│               <section class="blockname">...</section>                 │
│               <article class="blockname">...</article>                 │
│                                                                         │
│  القواعد:     - اسم بأحرف صغيرة وأرقام وشرطات                          │
│               - كل بلوك يُغلق بنفس اسمه                                │
│               - التداخل مسموح                                          │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```
