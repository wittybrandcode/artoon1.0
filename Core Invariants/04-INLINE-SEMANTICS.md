# ARTOON Inline Semantics

**الدلالات الداخلية**

---

## 1. المفهوم

الدلالات الداخلية تصف **حالة محلية مغلقة** داخل النص ولا تفتح سياقاً.

```
✓ تُستخدم داخل محتوى المكونات النصية
✓ كل تعبير داخلي مكتفٍ ذاتياً
✓ لا يسمح بالتداخل
```

---

## 2. الصيغة العامة

```
[modifier:: content]
[modifier+modifier:: content]
[modifiers+type:: content]
```

### 2.1 قاعدة الترتيب

```
✓ التوصيفات أولاً، النوع آخراً
✓ [s+time:: 2026-01-05]    ← تاريخ مهم
✓ [e+abbr:: HTML; HyperText] ← اختصار مؤكد
```

### 2.2 قاعدة المسافة

```
✓ صحيح:  [s:: نص مهم]
✗ خطأ:   [s::نص مهم]
```

---

## 3. المتحكمات الأساسية (Modifiers)

| الرمز | المعنى | HTML |
|-------|--------|------|
| `s` | أهمية قوية (strong) | `<strong>` |
| `e` | تأكيد (emphasis) | `<em>` |
| `u` | تسطير | `<u>` |
| `d` | شطب (deleted) | `<del>` |
| `mark` | تمييز/تظليل | `<mark>` |
| `sub` | نص منخفض | `<sub>` |
| `sup` | نص مرتفع | `<sup>` |

**ملاحظة:** `c` (الكود) ليس modifier بل مكون — راجع القسم 4.

---

## 4. الأنواع الدلالية (Types)

### 4.1 الأنواع الأساسية

| الرمز | المعنى | HTML | الصيغة |
|-------|--------|------|--------|
| `time` | تاريخ/وقت | `<time>` | `[time:: ISO; نص]` |
| `abbr` | اختصار | `<abbr>` | `[abbr:: الاختصار; التوسعة]` |
| `a` | رابط | `<a>` | `[a:: url; نص]` |

### 4.2 الأنواع الموسعة (التضمين الداخلي)

| الرمز | المعنى | الصيغة |
|-------|--------|--------|
| `img` | مرجع بصري سياقي | `[img:: path; alt; title]` |
| `audio` | إشارة صوتية | `[audio:: path; title]` |
| `video` | إشارة مرئية | `[video:: path; title]` |
| `file` | مرجع ملف | `[file:: path; label]` |
| `c` | كود سطري | `[c:: code; lang]` |

**ملاحظة:** الترتيب دائماً: الأساس أولاً (الاختصار، الرابط، التاريخ، المسار) ثم التفاصيل.

**هام:** هذه المكونات (img, audio, video, file, c) **لا تقبل modifiers** — راجع `10-INLINE-INTEGRATION.md`

**للتفاصيل الكاملة عن توصيفات المكونات:** راجع `11-INLINE-COMPONENT-ATTRIBUTES.md`

## 5. أمثلة المتحكمات

### 5.1 متحكم واحد

```artoon
>.p:: هذا نص يحتوي على [s:: كلمة مهمة] في المنتصف
>.p:: هذا [e:: تأكيد] وهذا [u:: مسطر]
>.p:: استخدم [c:: console.log()] للطباعة
>.p:: استخدم [c:: console.log(); js] للطباعة
>.p:: هذا [mark:: نص مميز] للانتباه
>.p:: الماء H[sub:: 2]O والتربيع x[sup:: 2]
```

**HTML:**
```html
<p>هذا نص يحتوي على <strong>كلمة مهمة</strong> في المنتصف</p>
<p>هذا <em>تأكيد</em> وهذا <u>مسطر</u></p>
<p>استخدم <code>console.log()</code> للطباعة</p>
<p>هذا <mark>نص مميز</mark> للانتباه</p>
<p>الماء H<sub>2</sub>O والتربيع x<sup>2</sup></p>
```

---

### 5.2 متحكمات متعددة

```artoon
>.p:: هذا [s+e:: مهم ومؤكد] معاً
>.p:: هذا [s+u:: مهم ومسطر]
>.p:: هذا [e+mark:: مؤكد ومميز]
```

**HTML:**
```html
<p>هذا <strong><em>مهم ومؤكد</em></strong> معاً</p>
<p>هذا <strong><u>مهم ومسطر</u></strong></p>
<p>هذا <em><mark>مؤكد ومميز</mark></em></p>
```

---

## 6. أمثلة الأنواع الدلالية

### 6.1 التاريخ (time)

```artoon
>.p:: تم النشر في [time:: 2026-01-05]
>.p:: تم النشر في [time:: 2026-01-05; الخامس من يناير]
>.p:: تاريخ مهم: [s+time:: 2026-01-05; يوم الإطلاق]
```

**HTML:**
```html
<p>تم النشر في <time datetime="2026-01-05">2026-01-05</time></p>
<p>تم النشر في <time datetime="2026-01-05">الخامس من يناير</time></p>
<p>تاريخ مهم: <strong><time datetime="2026-01-05">يوم الإطلاق</time></strong></p>
```

---

### 6.2 الاختصار (abbr)

```artoon
>.p:: لغة [abbr:: HTML; HyperText Markup Language] للويب
>.p:: معيار [e+abbr:: CSS; Cascading Style Sheets] للتنسيق
```

**HTML:**
```html
<p>لغة <abbr title="HyperText Markup Language">HTML</abbr> للويب</p>
<p>معيار <em><abbr title="Cascading Style Sheets">CSS</abbr></em> للتنسيق</p>
```

---

### 6.3 الروابط الداخلية (a)

```artoon
>.p:: زر [a:: https://example.com; هنا] للمزيد
>.p:: الموقع [a:: https://example.com]
>.p:: رابط [s+a:: https://important.com; مهم جداً]
```

**HTML:**
```html
<p>زر <a href="https://example.com">هنا</a> للمزيد</p>
<p>الموقع <a href="https://example.com">https://example.com</a></p>
<p>رابط <strong><a href="https://important.com">مهم جداً</a></strong></p>
```

## 7. القيود

### 7.1 لا تداخل

```
✗ خطأ:   [s:: نص [e:: داخلي] آخر]
✓ صحيح:  [s:: نص] و [e:: آخر]
```

### 7.2 ترتيب المتحكمات لا يغيّر المعنى

```
[s+e:: نص] = [e+s:: نص]
```

### 7.3 المتحكمات مكتفية ذاتياً

```
✓ كل [...] وحدة مستقلة
✓ لا تؤثر على ما قبلها أو بعدها
```

## 8. الاستخدام المزدوج (داخلي وخارجي)

بعض المكونات يمكن استخدامها كمكون مستقل أو داخل نص:

### 8.1 time

```artoon
>.time:: 2026-01-05                           ← مكون مستقل
>.p:: تم النشر في [time:: 2026-01-05]        ← داخلي
```

### 8.2 abbr

```artoon
>.abbr:: HTML; HyperText Markup Language      ← مكون مستقل
>.p:: لغة [abbr:: HTML; HyperText] للويب     ← داخلي
```

### 8.3 a (رابط)

```artoon
>.a:: https://example.com; اضغط هنا           ← مكون مستقل
>.p:: زر [a:: https://example.com; هنا]      ← داخلي
```

**القاعدة:** الدلالات الداخلية ترث الاتجاه من المكون الحاوي.
