# ARTOON Tables System

**نظام الجداول**

---

## 1. المفهوم

الجدول سياق مفتوح مثل القوائم، يحتوي على صفوف والصفوف تحتوي على خلايا.

```
✓ الجدول = سياق مفتوح
✓ الصفوف = عناصر متتالية
✓ الخلايا = قيم مفصولة بـ ;
✓ الإغلاق ضمني
```

---

## 2. الصيغة الأساسية

### 2.1 جدول بسيط

```artoon
>.table::
tr:: خلية 1; خلية 2; خلية 3
tr:: خلية 4; خلية 5; خلية 6
```

**HTML:**
```html
<table>
  <tbody>
    <tr>
      <td>خلية 1</td>
      <td>خلية 2</td>
      <td>خلية 3</td>
    </tr>
    <tr>
      <td>خلية 4</td>
      <td>خلية 5</td>
      <td>خلية 6</td>
    </tr>
  </tbody>
</table>
```

---

### 2.2 جدول مع رأس

```artoon
>.table::
th:: العمود 1; العمود 2; العمود 3
tr:: قيمة 1; قيمة 2; قيمة 3
tr:: قيمة 4; قيمة 5; قيمة 6
```

**HTML:**
```html
<table>
  <thead>
    <tr>
      <th>العمود 1</th>
      <th>العمود 2</th>
      <th>العمود 3</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>قيمة 1</td>
      <td>قيمة 2</td>
      <td>قيمة 3</td>
    </tr>
    <tr>
      <td>قيمة 4</td>
      <td>قيمة 5</td>
      <td>قيمة 6</td>
    </tr>
  </tbody>
</table>
```

---

## 3. عناصر الجدول

| العنصر | المعنى | HTML |
|--------|--------|------|
| `table` | حاوية الجدول | `<table>` |
| `th` | صف الرأس | `<tr><th>...</th></tr>` |
| `tr` | صف عادي | `<tr><td>...</td></tr>` |

---

## 4. قواعد الإغلاق

```
✓ الجدول يُغلق عند ظهور مكون جديد >.type::
✓ الجدول يُغلق عند نهاية الملف
✓ لا توجد علامات إغلاق صريحة
```

### مثال الإغلاق

```artoon
>.table::
th:: الاسم; العمر
tr:: أحمد; 25
tr:: سارة; 30
>.p:: فقرة بعد الجدول     ← هنا انتهى الجدول
```
