# ARTOON Reserved Blocks

**البلوكات المحجوزة**

---

## 1. المفهوم

ARTOON يحتوي على بلوكين محجوزين: `code` و `meta`.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   بلوكان محجوزان: code و meta                                          │
│                                                                         │
│   code:                                                                 │
│   ✓ المحتوى لا يُحلَّل كـ ARTOON                                        │
│   ✓ يُحفظ كما هو بالضبط                                                │
│                                                                         │
│   meta:                                                                 │
│   ✓ فقط حقول مخفية >.-:field:                                          │
│   ✓ مخفي في HTML output                                                │
│   ✓ للبيانات الوصفية (metadata)                                        │
│                                                                         │
│   جميع البلوكات الأخرى = بلوكات مخصصة (customBlock)                    │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 2. البلوك المحجوز: code

### 2.1 الصيغة الأساسية

```artoon
<code>.
// محتوى الكود
.<code>
```

### 2.2 مع تحديد اللغة

```artoon
<code:language>.
// محتوى الكود
.<code>
```

### 2.3 أمثلة

```artoon
<code:js>.
const x = 1;
console.log(x);
.<code>

<code:python>.
x = 1
print(x)
.<code>

<code:html>.
<div class="container">
  <p>Hello</p>
</div>
.<code>
```

### 2.4 المعاملة الخاصة

```
✓ المحتوى داخل <code>. لا يُحلَّل كـ ARTOON
✓ يُحفظ كما هو بالضبط (whitespace, symbols, etc.)
✓ رمز اللغة اختياري للتلوين النحوي
✓ الإغلاق .<code> إلزامي
```

### 2.5 اللغات المدعومة (أمثلة)

| الرمز | اللغة |
|-------|-------|
| `js` | JavaScript |
| `ts` | TypeScript |
| `python` | Python |
| `java` | Java |
| `csharp` | C# |
| `cpp` | C++ |
| `go` | Go |
| `rust` | Rust |
| `html` | HTML |
| `css` | CSS |
| `json` | JSON |
| `yaml` | YAML |
| `sql` | SQL |
| `bash` | Bash/Shell |
| `artoon` | ARTOON |

### 2.6 HTML الناتج

```html
<pre><code class="language-js">
const x = 1;
console.log(x);
</code></pre>
```

## 3. البلوك المحجوز: meta

### 3.1 الصيغة الأساسية

```artoon
<meta>.
>.-:fieldname: value
>.-:another: value
.<meta>
```

### 3.2 الخصائص

```
✓ محجوز (لا يمكن استخدامه كبلوك مخصص)
✓ يحتوي فقط على حقول مخفية (>.-:field:)
✓ لا يحتوي على محتوى عادي
✓ مخفي في HTML output
✓ يظهر في المحرر مع واجهة خاصة
```

### 3.3 الحقول المخفية

صيغة `>.-:field:` تعمل فقط داخل META block.

**⚠️ تمييز مهم: الحقول المخفية vs العناصر الأبناء**

#### الحقول المخفية (Hidden Fields)
```artoon
>.-:fieldname: value
```
- **تبدأ بـ `:` بعد `.-`**
- **الفاصل:** نقطة واحدة `:` بعد اسم الحقل
- مخفية في HTML output
- للبيانات الوصفية (metadata)
- **تعمل فقط داخل `<meta>` block**

#### العناصر الأبناء (Child Elements)
```artoon
>.-elementname:: content
```
- **لا تبدأ بـ `:`**
- **الفاصل:** نقطتان `::` بعد اسم العنصر
- مرئية في HTML output
- للمحتوى الهيكلي
- **تعمل في جميع البلوكات**

**الفرق الأساسي:**
| الصيغة | النوع | الظهور | الاستخدام |
|--------|-------|--------|-----------|
| `>.-:field:` | حقل مخفي | مخفي | metadata في META |
| `>.-element::` | عنصر ابن | مرئي | محتوى في أي بلوك |

### 3.4 أمثلة

```artoon
<meta>.
>.-:title: عنوان المستند
>.-:author: أحمد محمد
>.-:date: 2024-01-18
>.-:lang: ar
>.-:description: وصف المستند
.<meta>
```

### 3.5 الحقول الشائعة

| الفئة | الحقول |
|-------|--------|
| **المستند** | title, description, summary |
| **اللغة** | lang, dir, locale |
| **المؤلف** | author, email, organization |
| **التواريخ** | date, modified, published, version |
| **التصنيف** | tags, keywords, category, type |
| **الحقوق** | license, copyright, rights |
| **الحالة** | status, stage, visibility |
| **العلاقات** | source, parent, prev, next, related |

### 3.6 HTML الناتج

```html
<!-- META مخفي افتراضياً - لا يظهر في HTML -->
```

أو مع خيار `metaHandling: 'tags'`:

```html
<meta name="title" content="عنوان المستند">
<meta name="author" content="أحمد محمد">
<meta name="date" content="2024-01-18">
```

## 4. البلوكات المخصصة (غير محجوزة)

### 4.1 المفهوم

جميع البلوكات الأخرى (غير code و meta) هي بلوكات مخصصة (customBlock):

```artoon
<profile>.
>.p:: محتوى
.<profile>

<header>.
>.t1:: عنوان
.<header>

<card>.
>.-img:: icon.png
>.-p:: محتوى البطاقة
.<card>
```

**كلها بلوكات مخصصة** — لا فرق بينها من ناحية المعاملة.

### 4.2 العناصر الأبناء في البلوكات المخصصة

العناصر الأبناء `>.-element::` (بدون `:`) تعمل في جميع البلوكات المخصصة:

```artoon
<figure>.
>.-img:: photo.jpg
>.-figcaption:: وصف الصورة
.<figure>

<details>.
>.-summary:: العنوان
>.-p:: المحتوى
.<details>

<card>.
>.-img:: icon.png
>.-h3:: العنوان
>.-p:: النص
.<card>
```

### 4.3 الحقول المخفية (محظورة خارج META)

الحقول المخفية `>.-:field:` (التي تبدأ بـ `:`) **لا تعمل** خارج META:

```artoon
<profile>.
>.-:id: 12345          ❌ خطأ - حقل مخفي خارج META
>.p:: أحمد محمد
.<profile>
```

**الصيغة الصحيحة:**
```artoon
<meta>.
>.-:profile_id: 12345  ✅ في META
.<meta>

<profile>.
>.p:: أحمد محمد
.<profile>
```

## 5. الفرق بين code و meta والبلوكات الأخرى

| الخاصية | code (محجوز) | meta (محجوز) | البلوكات الأخرى |
|---------|--------------|--------------|-----------------|
| المحتوى | لا يُحلَّل | فقط حقول مخفية | يُحلَّل كـ ARTOON |
| الصيغة | `<code:lang>.` | `<meta>.` | `<name>.` |
| الإغلاق | `.<code>` | `.<meta>` | `.<name>` |
| المعاملة | خاصة | خاصة | عادية |
| HTML | `<pre><code>` | مخفي | `<div class="name">` |

## 6. ملخص

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      البلوكات المحجوزة في ARTOON                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  code (محجوز):                                                          │
│  ├─ الصيغة: <code:lang>. ... .<code>                                   │
│  ├─ المحتوى لا يُحلَّل كـ ARTOON                                        │
│  ├─ يُحفظ كما هو بالضبط                                                │
│  └─ اللغة اختيارية للتلوين النحوي                                      │
│                                                                         │
│  meta (محجوز):                                                          │
│  ├─ الصيغة: <meta>. >.-:field: value .<meta>                           │
│  ├─ فقط حقول مخفية >.-:field:                                          │
│  ├─ مخفي في HTML output                                                │
│  └─ للبيانات الوصفية (metadata)                                        │
│                                                                         │
│  جميع البلوكات الأخرى (profile, header, card, ...):                    │
│  ├─ بلوكات مخصصة (customBlock)                                         │
│  ├─ المحتوى يُحلَّل كـ ARTOON                                           │
│  ├─ يمكن تحويلها لأي tag في HTML                                       │
│  ├─ العناصر الأبناء >.-element:: تعمل                                  │
│  └─ الحقول المخفية >.-:field: لا تعمل (فقط في META)                   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```
