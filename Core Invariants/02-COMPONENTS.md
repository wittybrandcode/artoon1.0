## 1. المكونات النصية

### 1.1 الفقرة (p)

```artoon
>.p:: نص الفقرة بالعربية
<.p:: Paragraph text in English
```

| الخاصية | القيمة |
|---------|--------|
| النوع | نصي |
| المحتوى | نص متصل |
| HTML | `<p>` |

---

| `t3` | `<h3>` | أقسام فرعية |
| `t4` | `<h4>` | تفاصيل |
| `t5` | `<h5>` | تفاصيل دقيقة |

## 3. الفواصل البنيوية

### 3.1 الأنواع

```artoon
>.br
>.hr
>.wbr
```

| النوع | HTML | الوصف |
|-------|------|-------|
| `br` | `<br>` | سطر جديد |
| `hr` | `<hr>` | فاصل أفقي |
| `wbr` | `<wbr>` | نقطة كسر كلمة |

### 3.2 التركيب

```artoon
>.br;br
>.br;hr;br
```

**ملاحظة:** الفواصل لا تحتاج `::` لأنها بدون محتوى.

## 4. الكود

### 4.1 كود سطري (c) — Inline Code

```artoon
>.c:: console.log('hello')
>.c:: console.log('hello'); js
>.p:: استخدم [c:: npm install] لتثبيت الحزمة
>.p:: استخدم [c:: npm install; bash] لتثبيت الحزمة
```

| الخاصية | القيمة |
|---------|--------|
| النوع | سطري (inline) |
| القيمة 1 | الكود (إلزامي) |
| القيمة 2 | لغة البرمجة (اختياري) |
| الاستخدام | داخل فقرة أو عنوان |
| HTML | `<code>` |

**متى تستخدم:** لإدراج كود قصير داخل نص.

### 4.2 كود متعدد الأسطر (بلوك) — Code Block

```artoon
<code>.
const x = 1;
const y = 2;
console.log(x + y);
.<code>
```

### 4.3 كود مع تحديد اللغة

```artoon
<code:js>.
const x = 1;
console.log(x);
.<code>

<code:python>.
x = 1
print(x)
.<code>
```

| الخاصية | القيمة |
|---------|--------|
| النوع | بلوك مستقل |
| الاستخدام | كود متعدد الأسطر |
| HTML | `<pre><code class="language-X">` |

**متى تستخدم:** لعرض كود برمجي كامل.

### 4.4 الفرق الواضح

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   >.c:: code              ← سطري، داخل نص، لا يحتاج إغلاق              │
│   [c:: code]              ← سطري داخلي، داخل مكون آخر                  │
│                                                                         │
│   <code:lang>.            ← بلوك، مستقل، يحتاج إغلاق صريح              │
│   ...                                                                   │
│   .<code>                                                               │
│                                                                         │
│   ✗ ممنوع: خلط الاستخدامين أو أي صيغة أخرى                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```
