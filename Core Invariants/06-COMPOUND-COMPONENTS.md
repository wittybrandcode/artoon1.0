# ARTOON Compound Components

**المكونات المركبة**

---

## 1. المفهوم

المكونات المركبة هي مكونات تحتوي على عناصر فرعية تابعة لها.

```
✓ تستخدم >.- للعناصر الفرعية
✓ الاتجاه مُصرَّح في كل سطر
✓ الإغلاق ضمني عند ظهور مكون جديد
```

### الفرق بين التداخل في القوائم والمكونات المركبة

| القوائم | المكونات المركبة |
|---------|------------------|
| `-li::` (شرطة قبل النوع) | `>.-img::` (شرطة بعد الاتجاه) |
| ترث الاتجاه من الحاوية | تُصرِّح الاتجاه في كل سطر |
| للتداخل المتعدد المستويات | للعناصر التابعة فقط |

### رمز التبعية `-`

```
>.-type::    ← عنصر فرعي/تابع باتجاه RTL
<.-type::    ← عنصر فرعي/تابع باتجاه LTR
```

الـ `-` بعد الاتجاه مباشرة تدل على أن العنصر **تابع للسياق الأب**.

## 2. الشكل مع التعليق (figure)

### 2.1 الصيغة

```artoon
>.figure::
>.-img:: photo.jpg
>.-caption:: وصف الصورة
```

### 2.2 HTML الناتج

```html
<figure>
  <img src="photo.jpg" alt="">
  <figcaption>وصف الصورة</figcaption>
</figure>
```

### 2.3 أمثلة متنوعة

```artoon
>.figure::
>.-img:: chart.png
>.-caption:: رسم بياني للمبيعات السنوية

>.figure::
>.-video:: presentation.mp4
>.-caption:: فيديو توضيحي للمنتج

<.figure::
<.-img:: diagram.svg
<.-caption:: System architecture diagram
```

## 3. المحتوى القابل للطي (details)

### 3.1 الصيغة

```artoon
>.details:: العنوان المرئي
>.-p:: المحتوى المخفي
>.-p:: فقرة أخرى مخفية
```

### 3.2 HTML الناتج

```html
<details>
  <summary>العنوان المرئي</summary>
  <p>المحتوى المخفي</p>
  <p>فقرة أخرى مخفية</p>
</details>
```

### 3.3 أمثلة متنوعة

```artoon
>.details:: اقرأ المزيد
>.-p:: هذا النص مخفي افتراضياً
>.-p:: يظهر عند النقر على العنوان

>.details:: الأسئلة الشائعة
>.-t3:: ما هو ARTOON؟
>.-p:: صيغة ملفات محتوى دلالي
>.-t3:: لماذا ARTOON؟
>.-p:: للبساطة والوضوح

<.details:: Technical Details
<.-p:: This section contains technical information
<.-c:: const x = 42;
```

## 4. العناصر الفرعية المسموحة

### 4.1 داخل figure

| العنصر | الوصف |
|--------|-------|
| `-img` | صورة |
| `-video` | فيديو |
| `-audio` | صوت |
| `-caption` | تعليق توضيحي |

### 4.2 داخل details

| العنصر | الوصف |
|--------|-------|
| `-p` | فقرة |
| `-t1` إلى `-t6` | عناوين |
| `-ul`, `-ol` | قوائم |
| `-c` | كود |
| أي مكون آخر | حسب الحاجة |

## 5. قواعد الإغلاق

```
✓ المكون المركب يُغلق عند ظهور مكون جديد بدون -
✓ المكون المركب يُغلق عند نهاية الملف
✓ لا توجد علامات إغلاق صريحة
```

### مثال الإغلاق

```artoon
>.figure::
>.-img:: photo.jpg
>.-caption:: وصف
>.p:: فقرة جديدة     ← هنا انتهى الـ figure

>.details:: عنوان
>.-p:: محتوى
>.t2:: عنوان جديد    ← هنا انتهى الـ details
```
