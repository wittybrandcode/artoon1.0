# ARTOON Social Assets v2.0

**Style:** Black canvas · Inter Tight uppercase · Syntax Stripe accent

## Export sizes

| Asset | Size | Layout |
|-------|------|--------|
| GitHub social | 1280 × 640 | `logo-primary.svg` or `patterns/pattern-hero.svg` + wordmark |
| Open Graph | 1200 × 630 | Same |
| Avatar | 400 × 400 | `logo-mark.svg` centered |
| npm icon | 256 × 256 | Mark on `#000` |

## Hero template

```
Background: #000000 + pattern-hero.svg optional
Overline:   AI-NATIVE STRUCTURED FORMAT (Inter, 11px, #737373, tracking 0.2em)
Title:      ARTOON (Inter Tight, 88px+, white, tracking 0.12em)
Stripe:     syntax-stripe.svg below title
Tagline:    STRUCTURED FOR MACHINES · READABLE FOR HUMANS
```

Safe margin: **80px** on 1200×630.
