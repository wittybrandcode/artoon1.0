# دليل استخدام المعاينة
# Preview Panel Guide

## 🎯 نظرة عامة

تم إضافة لوحة معاينة مباشرة تعرض HTML المُحوَّل من محتوى ARTOON مع تطبيق الثيم المحدد.

---

## 🚀 كيفية الاستخدام

### 1. تشغيل المحرر
```bash
npm run dev
```

### 2. فتح المتصفح
```
http://localhost:3000/
```

### 3. تفعيل المعاينة
- اضغط على زر **"👁️ معاينة"** في الشريط العلوي
- ستظهر لوحة المعاينة بجانب المحرر

---

## ✨ الميزات

### معاينة مباشرة
- تحويل ARTOON إلى HTML في الوقت الفعلي
- تحديث تلقائي عند الكتابة
- عرض النتيجة النهائية

### تطبيق الثيم
- المعاينة تستخدم الثيم المحدد (Light/Dark)
- تغيير الثيم يحدث المعاينة فوراً
- جميع CSS Variables مطبقة

### معالجة الأخطاء
- عرض أخطاء التحليل بشكل واضح
- قائمة بالأخطاء مع أرقام الأسطر
- تصميم مميز للأخطاء

---

## 🎨 التخطيط

### Split View
```
┌─────────────────────────────────────┐
│  [محرر]  │  [معاينة HTML]          │
│          │                          │
│  ARTOON  │  <p>مرحباً</p>          │
│  Code    │  <h1>عنوان</h1>         │
└─────────────────────────────────────┘
```

### مع المصدر
```
┌──────────────────────────────────────────┐
│  [محرر]  │  [معاينة]  │  [مصدر]       │
└──────────────────────────────────────────┘
```

---

## 🔧 التحكم

### الأزرار
- **👁️ معاينة**: تفعيل/إخفاء المعاينة
- **🌙 / ☀️**: تبديل الثيم
- **عرض المصدر**: عرض كود ARTOON

### الحالات
- زر المعاينة يصبح أخضر عند التفعيل
- Header المعاينة يعرض الثيم الحالي

---

## 💡 نصائح

1. **للكتابة المركزة**: أخفِ المعاينة
2. **للمراجعة**: افتح المعاينة
3. **للتصدير**: تحقق من المعاينة أولاً
4. **للأخطاء**: راجع المعاينة للأخطاء

---

## 🎯 أمثلة

### محتوى بسيط
```artoon
>.p:: مرحباً بالعالم
```
**المعاينة**: `<p>مرحباً بالعالم</p>`

### محتوى مع تنسيق
```artoon
>.p:: هذا [s:: نص عريض] و [e:: نص مائل]
```
**المعاينة**: `<p>هذا <strong>نص عريض</strong> و <em>نص مائل</em></p>`

### محتوى مع خطأ
```artoon
>.invalid:: محتوى خاطئ
```
**المعاينة**: رسالة خطأ واضحة

---

## 🐛 استكشاف الأخطاء

### المعاينة لا تظهر
- تأكد من الضغط على زر "معاينة"
- تحقق من Console للأخطاء

### المعاينة لا تتحدث
- تأكد من تعديل المحتوى
- تحقق من وجود أخطاء في التحليل

### الثيم لا يُطبّق
- تأكد من تغيير الثيم من الزر
- أعد تحميل الصفحة
